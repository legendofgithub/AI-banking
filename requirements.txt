# Dependency policy (review fix: both bounds pinned; use requirements.lock.txt for exact repro).
#
# !! KEEP THIS FILE PURE ASCII -- DO NOT ADD NON-ASCII CHARACTERS !!
# pip reads requirements files using the system locale encoding. On a Chinese Windows
# machine (cp936/GBK) a single non-ASCII byte makes `pip install -r requirements.txt`
# abort with UnicodeDecodeError before installing anything -- i.e. a fresh clone cannot
# be set up at all. Keep notes in README / AGENTS.md (UTF-8) instead of here.
#
# - fastmcp cap <4: 4.x requires mcp>=2, while langchain-mcp-adapters 0.3.x pins mcp<2.
#   They cannot coexist in one venv (upgrading to 4.x breaks `import bank_core.mcp_server`).
# - Adapter is capped <0.4 too: 0.4+ may move to mcp 2.x, breaking the same constraint.
# Plan section 8 "lock versions from M0": range constraints (this file) + exact snapshot
# (requirements.lock.txt, generated by pip freeze) as double insurance. On a new machine,
# reproduce byte-for-byte with:
#   .venv/Scripts/python.exe -m pip install -r requirements.lock.txt
