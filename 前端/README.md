# AI 银行助手 · 移动端高保真原型(375×812)

> 依据 [`../提示词.md`](../提示词.md) 的全局设定、14 页分页提示词、交互连线表与验收清单 1:1 落地,
> 共 **19 个画板**,纯静态实现(无构建、无依赖、无网络请求),双击即可打开看。
> 设计口径与真实前端 `webui`(Next.js 对话式单页应用)一致:**所有动钱操作一律走「确认卡 → 支付密码 → 才执行」两步闸门。**

## 一、怎么看

| 文件 | 用途 | 打开方式 |
|------|------|----------|
| `index.html` | **全部页面总览画板**(19 个 375×812 画板并排,带编号/分组/说明) | 双击打开 |
| `app.html` | **可交互单机演示**(一台手机,按钮真的能点通全流程) | 双击打开,推荐投屏用 |

- 总览页:点画面里的任意按钮 → 自动跳到目标画板并高亮闪烁;顶部可「显示热区」(金色虚框标出所有可点区域)、按分组筛选。

- 交互版侧栏提供 4 条**推荐演示动线**,照着点即可走完答辩主线。

> 演示口令:支付密码 `888888`;演示账号 陈明 / `139****2233`(手机号已按规范脱敏显示)。

## 六、文件结构

```
前端/
├── index.html          全部页面总览画板(19 个画板 + 连线表 + 验收清单 + 规范速查)
├── app.html            可交互单机演示(带支付密码键盘、输入分流、演示动线)
├── assets/
│   ├── screens.js      19 个页面的结构化定义(可直接改文案/数据)+ 连线表 + 验收清单
│   ├── theme.css       移动端设计系统(令牌 / 手机画板 / 卡片 / 按钮 / 键盘 / 抽屉)
│   └── shell.css       工作台外壳样式(顶栏 / 工具条 / 网格 / 表格)
└── README.md           本文件
```

改文案或演示数据只需动 `assets/screens.js`(每个页面一个对象:`id / no / group / title / note / html`),
样式调整动 `assets/theme.css` 顶部的 `:root` 令牌即可。

## 七、与提示词清单的差异说明

1. **多出的画板**:P4-S(转账成功)、P6/P7a/P7b/P8a/P8b/P9a/P9b/P10a/P10b 的双态拆分为独立画板,
   便于墨刀式评审逐页看图(提示词里以「变体」描述),内容与口径完全一致。
2. **P6 / P11 允许卡片区内滚动**:内容天然长于 812px(与真实 App 一致),其余 17 页均一屏放完。
3. **重绘用途**:这套 HTML 也能当墨刀投放前的「施工图」——`assets/screens.js` 里的每个页面
   都可以直接对照着画,配色/字号/文案/间距都是最终值。
